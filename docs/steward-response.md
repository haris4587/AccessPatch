Implemented a fixer-bound commit/reveal flow. Before publishing evidence, the fixer commits a SHA-256 hash of a secret 32-byte salt, sender address, chain ID, contract address, bounty ID, report URL, and page/report hashes. Reveal requires the same sender, exact preimage, a 60-second minimum age, and an unused commitment. Copying the original commitment or reveal cannot redirect payment. The app now provides separate Commit and Reveal actions.
